# Future work

1. Elicit and validate trust concerns with logistics operators, managers,
   compliance professionals, customers, and DPOs under an approved protocol.
2. Define a reviewed risk-labeling rubric and independently annotate realistic
   de-identified or carefully simulated scenarios.
3. Expand E1 to repeated stratified seeds, a genuinely fine-tuned compact
   transformer, uncertainty calibration, memory measurement, and paraphrase
   robustness.
4. Add a labelled retrieval benchmark and compare lexical, dense, and hybrid
   search with provenance audits.
5. Evaluate optional LLM providers against pre-registered claim sets, including
   contradictory and adversarial evidence, without treating generated
   confidence as calibrated probability.
6. Compare semantic similarity and NLI verification; report NLI as a fallible
   model rather than factual proof.
7. Extend E5 to classifier error profiles, threshold sensitivity, and measured
   review-time distributions while keeping decisions human-controlled.
8. Evaluate privacy filters with synthetic canaries first, then only with
   properly governed data and a documented threat model.
9. Add database-backed audit retention/integrity controls, API authentication,
   access control, and production-grade observability before any deployment.
10. Automate trace-link checks and conduct independent review of semantic
    mapping quality.
